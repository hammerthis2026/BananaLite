# Banana Lite

A planned performance-focused Android fork of Banana Native for compatible ARM64 devices, with particular attention to older GPUs and memory-constrained phones.

## Planned profiles
- Ultra Lite: older GPUs and limited RAM.
- Balanced: mid-range devices.
- Performance: higher-end devices.
- Custom: adjustable settings.

Automatic frame generation is planned where required files and GPU capabilities are available, with a manual disable option. Compatibility and FPS are not guaranteed.

## Initial test device
Snapdragon 732G, Adreno 618, 6 GB RAM, Turnip. This is a test configuration, not a hardware requirement.

## Status
Experimental source prototype; Android APK not yet built or benchmarked. Profiles are planned, not implemented or validated. Initial game testing focuses on Donkey Kong Bananza.
